MOD NAME:  Echelon Mod Manager
CATEGORY:  Miscellaneous

SHORT DESCRIPTION (317 of 350 characters):
A free mod manager for Helldivers 2. Keep every mod in one library, sort them into profiles like loadouts, and deploy a whole profile in one click. Handles mod options and Bingus Shared Loader mods, warns about clashes and solo-only mods, and imports your library and profiles from HD2 Arsenal. Every feature is free.

[size=5][b]Description[/b][/size]
Echelon keeps every Helldivers 2 mod you download in one library, lets you sort them into [b]profiles[/b] (think loadouts for your mods) and puts a whole profile into the game with one click. When you want a clean game again, one more click takes every mod back out.

[b]Echelon is free, and every feature is for everyone. Nothing is locked.[/b]

[size=5][b]Installation instructions[/b][/size]
[list=1]
[*]Download the file from the [b]Files[/b] tab and unzip it.
[*]Run [b]Echelon-Setup-x.y.z-nexus.exe[/b]. It installs for your user only, so no admin rights are needed.
[*]Windows may say "Windows protected your PC" because Echelon is new and not code-signed yet. Click [b]More info[/b], then [b]Run anyway[/b].
[*]The first-time setup finds your game folder, asks you to accept the licence, and asks which online extras you want (all of them start off).
[*][b]Coming from HD2 Arsenal?[/b] Setup offers to bring over your mods, profiles, load order, separators, tags and option choices. Arsenal's own files aren't changed.
[/list]
[b]Updating:[/b] track this page to hear about new versions, then run the new installer over the old one. Your mods, profiles and settings stay where they are.

[b]Checking your download:[/b] the zip includes a [b].sha256[/b] file. To check the installer, open a command prompt in that folder and run
[code]certutil -hashfile Echelon-Setup-x.y.z-nexus.exe SHA256[/code]
The result should match the number in the .sha256 file.

[size=5][b]Main features[/b][/size]
[list]
[*][b]Library[/b]: every mod as a picture card or in a compact list, with a details panel showing its description, options, size, which profiles use it, and its web page.
[*][b]Profiles[/b]: load order, separators, tags and per-mod options. Switch between loadouts in a second.
[*][b]One-click Deploy and Purge[/b]: Deploy puts exactly the open profile into the game. Purge takes every mod out, including ones installed by hand or by other tools.
[*][b]Mod options[/b]: pick versions, colours and extras. Mods that ship their variants as folders get proper options too, instead of being cut down to one version.
[*][b]Bingus Shared Loader support[/b]: Echelon recognises the loader and the mods that need it, warns when a profile is missing it, and keeps it in the right spot so Bingus mods start.
[*][b]Clash checks[/b]: see when two mods change the same thing, and which one wins.
[*][b]Import from HD2 Arsenal[/b]: if a mod came as several versions without a manifest, Arsenal kept only the one picked back then. Echelon lists those mods under [b]Check options[/b], with a button to get the full download so you can choose again.
[*][b]Add from a link[/b]: paste a Nexus page and Echelon picks up your manual download automatically. Google Drive, Dropbox, GitHub and Discord links work too.
[*][b]Share profiles[/b] as a short code ([b]EC-XXXX-XXXX[/b]) or a link. Friends see exactly which mods they're missing.
[*][b]Solo-only mods[/b]: some Lua mods change the game for everyone in the lobby. Mark them as solo only and they get a SOLO badge, plus a reminder to turn them off before public lobbies when you deploy. Echelon suggests the mark when a mod's description mentions solo play or anti-cheat.
[*][b]Developer Suite for mod authors[/b]:
[list]
[*][b]Mod Builder[/b]: build a mod with options and a manifest without writing any JSON.
[*][b]Repatcher[/b]: keeps your own model and text mods working after a game update. Mods that need it get a NEEDS REPATCH badge.
[*][b]Mod Inspector[/b]: see what's inside your mod, check it for common problems, and compare versions.
[*][b]Retagger[/b]: a shortcut to [url=https://www.nexusmods.com/helldivers2/mods/15413]HD2 Retagger[/url] by soulls00 for moving an armor look onto other armors. Get it from their page; Echelon only starts it.
[/list]
The Repatcher and Mod Inspector are for your own mods. Before they open a mod, they ask you to confirm it's yours or that its author allows it. Many authors give that permission in the Permissions section of their Nexus page; if not, ask them first.
[*][b]Languages[/b]: English, Simplified Chinese and Japanese.
[/list]

[size=5][b]FAQ[/b][/size]
[b]Will it mess up my mods or my game?[/b]
Echelon never edits your mod files in place. It keeps its own copy of each mod, and the Repatcher always works on copies, with a way to put the originals back. Deploy only touches mod files in the game's data folder, and Purge takes them all out again.

[b]Can I go back to Arsenal or another manager?[/b]
Yes. Click [b]Purge[/b] in Echelon first so the game is clean, then deploy from the other manager. Echelon's import doesn't change anything in Arsenal.

[b]Does it go online?[/b]
Only if you turn it on. Translating mod descriptions into your language uses the MyMemory service. Sharing profiles only connects when you share or open one. This Nexus version never checks for updates by itself. No tracking, no ads.

[b]My antivirus flagged it.[/b]
Some antivirus programs flag new apps built with PyInstaller by mistake. Check the installer against its .sha256 file, and let us know in the Bugs tab so we can report it as a false positive.

[b]Something went wrong. How do I report it?[/b]
Post in the Bugs tab and attach your latest log from [b]%APPDATA%\Echelon\logs[/b]. Settings > System > About shows the exact path.
